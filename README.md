# Шахматы (на основе Python-checkers)

Шахматная игра с графическим интерфейсом на Tkinter и встроенным ИИ, построенная
по архитектуре проекта [Python-checkers](https://github.com/QuadDarv1ne/Python-checkers).
Идея в том, чтобы переиспользовать «оболочку» оригинала (Tkinter, роли модулей,
стиль API), заменив шашечное ядро шахматным.

## Запуск

```bash
python main.py
```

Требуется Python 3.10+ со стандартным модулем `tkinter` (на Debian/Ubuntu:
`sudo apt install python3-tk`). Сторонних зависимостей нет.

Тесты и дымовые проверки:

```bash
python tests/run_all.py         # все наборы ниже подряд (код выхода 0 только если все PASS)
python tests/selfcheck.py       # правила: ходы, шах/мат/пат, en passant, рокировка, превращение
python tests/perft.py           # генерация ходов: perft на эталонных позициях (старт depth4=197281, Kiwipete и др.)
python tests/engine_smoke.py    # движок: ход из старта + мат в 1 + мат в 2
python tests/game_smoke.py      # game.py: статус, история, ничьи, SAN, FEN/PGN (экспорт и импорт)
python tests/tactical_test.py   # движок: взятие материала, форк, защита фигур, мат в 1
python tests/repetition_test.py # движок: детекция троекратного повторения внутри поиска
```

## Возможности

- Полные правила шахмат: ходы всех 6 фигур, рокировка (короткая и длинная),
  взятие на проходе, превращение пешки (с выбором фигуры), шах, мат, пат.
  Корректность генерации ходов верифицирована perft-тестом на 5 эталонных
  позициях, включая «Kiwipete» (depth 3 = 97862 узлов).
- Ничьи: правило 50 ходов, троекратное повторение (ключ позиции учитывает клетку
  en passant только если сторона хода действительно может ею воспользоваться —
  по FIDE ст. 9.2), недостаточный материал.
- ИИ на negamax + alpha-beta + quiescence + таблица транспозиций + null-move
  pruning + check extensions + late move reductions + аспирационные окна в корне;
  оценочная функция с piece-square таблицами, пешечной структурой
  (сдвоенные/изолированные), бонусом за пару слонов и фазозависимой оценкой
  короля (миттельшпиль — пешечный щит, эндшпиль — выход в центр). 4 уровня.
- Игра за белых или за чёрных (ИИ ходит первым, если вы выбрали чёрных).
- Анимация хода (скольжение фигуры), подсветка последнего хода и короля под шахом.
- Подсказка лучшего хода (стрелка на доске) с оценкой позиции и главным
  вариантом (PV) из таблицы транспозиций.
- Панель взятых фигур и материального баланса.
- Отмена хода (откатывает пару «ход ИИ + ход игрока»), новая партия, переворот
  доски, панель истории ходов в нотации SAN.
- Экспорт партии в PGN-файл и загрузка партии из PGN (разыгрывает ходы до
  текущей позиции; поддерживает заголовки, комментарии `{...}` и `;` до конца
  строки, варианты, NAG,
  нечётный ход по `[FEN]`); FEN — и в буфер обмена, и загрузка из FEN
  (вставка позиции для анализа/доигровки).
- Горячие клавиши: Ctrl+N (новая), Ctrl+Z (отмена), Ctrl+H (подсказка),
  Ctrl+F (перевернуть доску).

## Управление

- Клик по своей фигуре — выбор, ходы подсвечиваются точками (тихий ход) и
  кольцами (взятие).
- Клик по подсвеченной клетке — ход. Пешка на последней горизонтали открывает
  диалог выбора фигуры превращения.
- Меню: **Игра** (Новая / Отменить / Подсказка / Сохранить PGN / Загрузить PGN
  / Скопировать FEN / Загрузить FEN / Выйти), **Сторона**, **Сложность**,
  **Вид** (Перевернуть доску).

## Архитектура

Пакет `chess_game/` повторяет роли модулей из `checkers/` оригинала:

| Модуль | Роль | Соответствие в Python-checkers |
| --- | --- | --- |
| `enums.py` | `SideType`, `PieceType`, `DifficultyType` | `checkers/enums.py` |
| `constants.py` | размеры, цвета, стоимости фигур, направления | `checkers/constants.py` |
| `point.py` | клетка доски (`__slots__`) | `checkers/point.py` |
| `move.py` | ход с флагами рокировки/en passant/превращения | `checkers/move.py` |
| `piece.py` | фигура (тип + цвет) | `checkers/checker.py` |
| `field.py` | доска 8×8, расстановка, материал, копия | `checkers/field.py` |
| `rules.py` | генерация ходов, атака клетки, шах/мат/пат, apply/undo | `checkers/rules.py` |
| `engine.py` | negamax + alpha-beta + quiescence + итеративное углубление | `checkers/engine.py` |
| `game.py` | состояние партии, история, статус, нотация SAN | `checkers/game.py` |
| `main.py` | Tkinter GUI | `main.py` оригинала |

### Что переиспользовано из оригинала

- Структура проекта и разделение на модули по тем же ролям.
- API `SideType.opposite`, `DifficultyType` со свойствами `depth` / `time_limit`
  / `noise_scale` / `name_ru`.
- `Point` с `__slots__`; `Field.copy` минуя `__generate` (чтобы не строить доску
  дважды на каждой ветке поиска).
- Шаблон движка: итеративное углубление, MVV-LVA ordering, killer-ходы,
  noise для «осмысленной случайности» на лёгких уровнях, отмена по `threading.Event`.

### Что переписано по существу

- Генерация ходов для 6 типов фигур (вместо 2 типов шашек).
- Рокировка, взятие на проходе, превращение — этого в шашках нет.
- Обнаружение атаки клетки (`is_square_attacked`) — нужно для шаха и для
  «не через шах» при рокировке.
- Оценка позиции: материал + piece-square таблицы + пешечная структура
  (штраф за сдвоенные/изолированные пешки) + бонус за пару слонов + фазозависимая
  оценка короля. Фаза считается по не-пешечному материалу: в миттельшпиле король
  штрафуется за отсутствие пешечного щита перед собой, в эндшпиле —
  интерполируется к таблице, поощряющей выход в центр (вместо
  «центр/защита/продвижение» из шашек).
- Quiescence-поиск на дне — без него движок «зависает» на горизонте и отдаёт
  фигуры под немедленный ответ. Под шахом stand-pat незаконен, поэтому там
  quiescence ищет все уклонения (evasions), а не только взятия.
- Таблица транспозиций с корректной кодировкой мат-оценок по глубине (мат
  хранится относительно узла, чтобы читаться с любой ply), null-move pruning
  (R=2) с защитой от цугцванга по не-пешечному материалу, check extensions
  (ход под шахом ищется на 1 глубже), late move reductions (поздние тихие ходы
  ищутся мельче с пересмотром при fail-high), аспирационные окна в корне (с 4-й
  глубины поиск идёт в окне ±0.5 пешки вокруг оценки прошлой итерации, при
  fail-low/fail-high — полный пересмотр), TT-move в ordering. После поиска из TT
  извлекается главный вариант (PV).
- Детекция троекратного повторения внутри поиска: движок знает историю позиций
  реальной партии и на каждом узле считает повторения (история до корня + текущий
  путь); на 3-м возникновении позиции возвращает ничейный 0 — это позволяет
  засчитать ничью по повторению и избежать зевка в линиях, ведущих к повтору.
  Ничья по правилу 50 ходов тоже видна поиску: тихий ход, доводящий счётчик
  до 100, оценивается как 0 (мат важнее ничьей). На уровне партии те же ничьи
  фиксирует Game.
- Нотация SAN (в оригинале — шашечная нотация), плюс сериализация FEN и PGN
  в обе стороны: экспорт (`to_san`/`fen`/`pgn`) и импорт (`from_san`/`from_fen`/
  `from_pgn`/`parse_fen` со строгой валидацией: ровно по королю у каждой стороны,
  каждая горизонталь из 8 клеток, отсутствие пешек на крайних горизонталях,
  сторона без хода не под шахом, права рокировки только с королём и ладьёй
  на исходных клетках, клетка en passant пуста и за ней стоит пешка двойного хода).
  `from_pgn` разбирает заголовки (включая `[FEN]`), комментарии `{...}` и `;`, вложенные
  варианты и NAG.

### Отличия от оригинала по дизайну

- В шашках ход — это серия взятий (`Turn`); в шахматах ход — одна полуплоскость,
  поэтому `Turn` не нужен, а легальность проверяется прямо в поиске (после
  `apply_move` смотрим, не оказался ли свой король под шахом) — это дешевле
  отдельного прохода `legal_moves`.
- Движок использует таблицу транспозиций с кодировкой мат-оценок по глубине
  и null-move pruning — этого в шашечном оригинале нет (там серия взятий
  считается одним ходом, иные ускорения не так критичны). Мат-оценки
  хранятся относительно узла, чтобы корректно читаться с любой глубины.
- GUI проще, чем в оригинале (без тем/курсоров/звука): канвас с глифами фигур,
  подсветка, анимация хода, диалог превращения, ИИ в отдельном потоке с
  обменом через очередь (Tkinter не потокобезопасен — поток не вызывает
  `root.after` напрямую).

## Производительность ИИ

Из стартовой позиции на машине из песочницы (с null-move pruning и TT):

| Уровень | Целевая глубина | Достигнутая | Время | Узлы |
| --- | --- | --- | --- | --- |
| Лёгкий | 2 | 2 | ~0.05 с | ~0.9 тыс. |
| Средний | 3 | 3 | ~0.3 с | ~3.7 тыс. |
| Сложный | 5 | 5 | ~4.1 с | ~50 тыс. |
| Гроссмейстер | 7 | 6 | ~10 с (лимит) | ~150 тыс. |

Чистый Python, без битовых досок — поэтому Гроссмейстер не претендует на
сильную игру, но играет осмысленно и находит короткие маты (мат в 1 и в 2
проверяются тестами).

## Известные ограничения

- FEN и PGN — экспорт и импорт (меню «Загрузить FEN»/«Загрузить PGN»,
  `Game.from_fen`/`from_pgn`).   `from_pgn` читает первую партию файла и не проверяет корректность заголовков
  (номера хода, результат и т. п.) — только разыгрывает ходы; некорректный
  SAN или нелегальный ход вызывает `ValueError` с номером хода.
- Нет часов, сетевой игры, дебютной книги и эндшпильных таблиц.
- Шрифт фигур — `DejaVu Sans` (содержит шахматные глифы); при отсутствии
  глифов в системе фигуры могут отображаться прямоугольниками.
